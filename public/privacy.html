Privacy

Privacy policy.

How this portfolio handles data, in plain terms. There isn't much to it, so this is short.

The short version

This site doesn't collect anything on its own.

This is a personal portfolio: static pages served from Firebase Hosting. There is no backend, no database, no account system and no forms to fill in. No page sets cookies, and none of the code writes to localStorage or sessionStorage. There is no analytics script, no tracking pixel, and no advertising anywhere on the site.

What actually happens when you visit

Two things touch your data, because the page depends on them to render.

Firebase Hosting (a Google service) serves the files. Like any web host, it keeps standard server request logs — IP address, timestamp, requested path and browser user-agent — for operating and securing the service. There is no separate analytics layer on top of this; I don't see individual visits.

Google Fonts. The pages load Instrument Sans and IBM Plex Mono from fonts.googleapis.com and fonts.gstatic.com. Loading a webfont means Google's font servers receive the visitor's IP address and user-agent as part of serving those files, the same as any external font or image request would.

That's the complete list of third parties. Nothing else is contacted from any page.

Inside Microsoft Teams

The Teams tab reads a theme colour and opens links. That's it.

If you're viewing this through the Teams personal tab, the page also loads the Microsoft Teams JavaScript SDK from res.cdn.office.net. It is used for exactly two things: reading which colour theme the Teams client is in (default, dark or high contrast) so the page can match it, and opening external links in your browser instead of trying to navigate inside the Teams frame. The app requests no Teams permissions, reads no user, chat, calendar or organisational data, signs nobody in, and stores nothing about who is viewing it. It is a read-only window onto the same public pages described above.

No accounts, no sharing, no selling

There's nothing here to log into, and nothing to sell.

There is no sign-in anywhere on this site, so there are no passwords or profiles to worry about. I don't run advertising, retargeting or any cross-site tracking here, and there is no data collected on this site to share or sell to anyone. If a future version of the site ever needs a contact form or something similar that changes this, this page will say so before it ships.

Children's privacy

Nothing here is aimed at children, and none of this changes if you are one.

This is a professional portfolio, not a service aimed at children. Since the site collects nothing of its own regardless of who is visiting, there is no age-specific handling to describe beyond what is already stated above.
